# Protocol: Do binding control vectors induce the native computation?

*Causal Maps · 2026-07-13 · post-`ROUTER_READ_AMBIGUOUS`*
*Status: **COMPLETE — `CONTROL_NATIVE_LIKE_NO_CONVERGENCE`.***

---

## Scientific question

> Does adding a value direction at L2 merely force the answer through an
> alternate pathway, or does it cause the network to reconstruct the same
> downstream state used by a natural textual value change?

This is the first direct test of the candidate thesis:

> **Low-dimensional control interface → high-dimensional native computation.**

The thesis is **not licensed** by prior results. `PROTOCOL_COMPATIBLE` establishes
behavioral interoperability; Makelov/Grant-style dormant or divergent pathways
remain live alternatives.

---

## Data and cross-fitting

- Model: Qwen2.5-7B-Instruct, 8-bit, residual stream fp16.
- Skill: existing 50 Variable pairs = 5 variable-name templates × 10 value pairs.
- Injection: L2 `val_slot`, α=1.
- Five-fold template cross-fit:
  - hold out one variable-name template;
  - derive each per-value \(\Delta_v\) from the other four templates only;
  - evaluate on all ten held-out pairs;
  - repeat for all five templates.
- No test activation contributes to its direction.

Conditions on the held-out clean prompt:

1. `CLEAN`: native source value \(v_0\).
2. `CF`: natural textual counterfactual value \(v_1\).
3. `ADD`: clean + cross-fitted \(\Delta_{v_1}\).
4. `WRONG`: clean + a cyclic wrong-value direction.
5. `RAND`: clean + per-row same-norm random directions (100 aggregate null draws).

---

## Trajectory measurements

Capture post-layer residuals at layers \(\{2,4,8,14\}\), at:

- `val_slot` — the written memory site;
- `last` — the answer/query readout position.

For every held-out pair:

\[
d_{\mathrm{native}}(L,p)=h_{\mathrm{CF}}(L,p)-h_{\mathrm{CLEAN}}(L,p)
\]

\[
d_{\mathrm{add}}(L,p)=h_{\mathrm{ADD}}(L,p)-h_{\mathrm{CLEAN}}(L,p)
\]

Metrics:

- alignment \(a(L,p)=\cos(d_{\mathrm{add}},d_{\mathrm{native}})\);
- normalized error
  \(e(L,p)=\|d_{\mathrm{add}}-d_{\mathrm{native}}\|/
  \|d_{\mathrm{native}}\|\);
- activation norm ratio \(\|h_{\mathrm{ADD}}\|/\|h_{\mathrm{CF}}\|\);
- output effect = change in logit difference \(v_1-v_0\).

Primary downstream checkpoint: **L8**. L4/L14 are trajectory support; L2 is
the injection baseline. No best-layer selection.

---

## Causal mediation at L8 `val_slot`

On each held-out clean prompt:

1. **Natural patch:** patch \(h_{\mathrm{CF}}(L8,\mathrm{val})\) into CLEAN.
2. **Generated-state patch:** patch
   \(h_{\mathrm{ADD}}(L8,\mathrm{val})\) into CLEAN.
3. **Block:** run ADD at L2, then overwrite L8 val-slot with
   \(h_{\mathrm{CLEAN}}(L8,\mathrm{val})\).

These compare full states generated by real model runs; they do not use
`keep_span` / `keep_res`.

## Frozen gates

### G0 — behavioral elicitation

- CLEAN greedy source accuracy ≥80%;
- CF greedy target accuracy ≥80%.

Fail → `TRAJECTORY_INELICITABLE`, stop.

### O1 — control works

Mean ADD output effect \(>0\), p<0.01 vs same-norm random ADD null.

### A1 — downstream native alignment

At L8 `val_slot`:

- mean cosine \(a_{\mathrm{ADD}}\ge0.50\);
- ADD cosine beats random-direction null, p<0.01;
- ADD cosine exceeds WRONG cosine.

### A2 — reconstruction/convergence

At `val_slot`:

- \(e(L8)\le0.75\), and
- \(e(L8)\le0.80\times e(L2)\).

This distinguishes downstream reconstruction from a control vector that merely
persists without becoming more native-like.

### Q1 — propagation to query state

At L8 `last`:

- mean cosine ≥0.30;
- beats random-direction null, p<0.01.

### M1 — generated state is sufficient downstream

\[
\frac{\mathrm{effect}(\mathrm{patch}\ h_{\mathrm{ADD},L8})}
{\mathrm{effect}(\mathrm{patch}\ h_{\mathrm{CF},L8})}\ge0.50
\]

with both effects positive.

### M2 — generated state is necessary for ADD effect

\[
\mathrm{block\_fraction}=
\frac{\mathrm{effect}(\mathrm{ADD})-\mathrm{effect}(\mathrm{ADD+block})}
{\mathrm{effect}(\mathrm{ADD})}\ge0.50
\]

### D1 — basic distribution guard

At L8 val-slot, mean
\(\|h_{\mathrm{ADD}}\|/\|h_{\mathrm{CF}}\|\in[0.8,1.2]\).

This is necessary but not sufficient evidence of on-manifold behavior; A1/A2
and native-patch mediation are the stronger checks.

## Decision after this kernel

- `CONTROL_GENERATES_NATIVE_STATE`:
  pre-register cross-family replication and then attention-path mediation.
- `CONTROL_NATIVE_LIKE_NO_CONVERGENCE`:
  report a native-like downstream handle, but do not claim generation.
- `CONTROL_ALTERNATE_PATH`:
  stop the generator thesis; strongest result becomes control without faithful
  natural mechanism.
- `CONTROL_NULL` / `INELICITABLE`: stop.

No layer sweep, no α sweep, no alternate templates, no rescue kernel before
logging the verdict.

## Result

G0, O1, A1, Q1, M1, M2, and D1 passed. A2 failed:

- L2 val-slot: cosine 0.9922, normalized error 0.1201;
- L8 val-slot: cosine 0.9920, normalized error 0.1242;
- L8 last-position cosine: 0.7303 (random-null mean 0.3329, p=.0099);
- generated/native L8 patch-effect ratio: 0.9965;
- blocking the L8 val-slot removed 92.7% of the ADD effect.

The state was already native-like immediately after injection and did not
converge further downstream. Therefore the preregistered verdict is
`CONTROL_NATIVE_LIKE_NO_CONVERGENCE`, not
`CONTROL_GENERATES_NATIVE_STATE`.

Important scope: every target value has one fixed source value in this dataset
(for example dog→cat) and the five folds vary only the variable name. The 0.992
cosine therefore establishes context-robustness of the same value transition;
it does not establish a source-invariant abstract value code.
