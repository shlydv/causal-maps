# Paper 2: prospective latent-instruction compiler assay

Status: frozen before GPU output, 2026-07-27.

## Question

Can a small, training-derived early activation program cause a frozen
transformer to construct the correct context-specific later operation state,
without observing or transplanting the held-out target state?

This is not another universal late-vector test. The proposed invariant is an
early operation code; its predicted consequence is a different receiver-
specific state after the model's intervening layers have processed it.

## Frozen model and causal interface

- Qwen2.5-7B-Instruct, 8-bit, Tesla T4.
- Candidate early block outputs: L2, L6, L10, L14 and L18.
- Early program locus: the two position-matched three-token command
  occurrences (six residual states total).
- Generated-state checkpoint: the same six positions at L21, with the
  three-token answer occurrence primary.
- Downstream checkpoints: processed final-token states at L24 and L27, after
  subtracting the generated L21 final answer-token state.
- Directions: epistemic to search and search to epistemic.
- Clean and natural value histories remain separate throughout.

## Prospective splits

Training families:

1. private belief;
2. latest update;
3. key-value lookup;
4. conditional selection.

Calibration families:

1. constraint elimination;
2. temporal slot.

Held-out test families:

1. maximum-score comparison;
2. two-hop pointer traversal.

The early code is the mean paired target-minus-source residual difference
over the training families, both clean/natural histories, all training rows,
and both training lexical panels:

- BELIEF / SEARCH;
- THINK / FIND.

Calibration uses THINK/FIND on disjoint directed value pairs. The selected
layer is the layer maximizing the minimum of L21 generated-state progress and
processed-L27 route progress across all calibration cells; the earlier layer
breaks exact ties. Calibration must achieve at least +0.20 and preserve at
least 80% value accuracy. Otherwise the run stops with a clean calibration
null.

The only test panel is the unseen KNOW/LOOK panel on twelve further histories.
The selected layer, both directed codes, six-position layout, random codes and
all hashes are frozen before any held-out target activation is evaluated.

## Test interventions

For both held-out families and both directions:

1. source and natural target baselines;
2. exact same-row target states at the selected early layer and all six
   command positions (compiler-capacity oracle);
3. the training-derived six-position early code (primary intervention);
4. the same code restricted to the answer occurrence;
5. the same code restricted to the instruction occurrence;
6. the same six-state code at six matched identical-token positions;
7. sign reversal;
8. nineteen seeded same-norm isotropic random six-state codes;
9. exact matched L21 target-state transplant (late assay oracle);
10. early code followed by restoration of the source L21 answer state
    (mediation block);
11. the L21 answer state generated by the early code transplanted into a
    fresh source run without the early intervention (mediation rescue).

No test target state contributes to the primary code, selected layer, scale,
positions, controls or randomization.

## Measurements

For every row:

- raw L21 answer-state progress toward the natural held-out target;
- processed L24 and L27 progress toward the natural target route;
- distance to the target state;
- correct value-answer accuracy.

Contextual compilation is assessed after subtracting each cell's mean
operation displacement. The receiver-matched generated L21 residual must
predict its own target residual better than all nineteen frozen row
derangements. Every deranged target is differenced from the same receiver
source state, preventing the common source term from manufacturing a matching
advantage. This distinguishes receiver-specific construction from merely
carrying one shared early displacement forward.

## Frozen gates

The late L21 exact-state oracle must first establish an interpretable causal
target in every test cell.

The exact early compiler-capacity oracle passes a cell when:

- mean L21 progress is at least 0.60;
- mean processed-L27 progress is at least 0.40;
- at least 20 of 24 rows move positively at both checkpoints;
- minimum value accuracy is at least 80%.

The portable early code passes a cell when:

- mean L21 progress is at least 0.25;
- mean processed-L27 progress is at least 0.25;
- it recovers at least half the exact-early L27 effect;
- at least 20 of 24 rows move positively at both checkpoints;
- minimum value accuracy is at least 80%.

Causal mediation requires source-state restoration at L21 to remove at least
70% of the primary L27 effect and generated-state rescue to recover at least
70%, in every cell.

Specificity requires:

- identical-position and sign-reversal breadth no greater than half the
  primary score;
- no frozen random code to equal or exceed the primary breadth score
  (add-one empirical p = 0.05);
- receiver-matched residual reconstruction to beat all nineteen frozen row
  derangements, with at least 10% median error reduction.

The instruction-only and answer-only arms are localization ablations, not
nulls. Either may equal the six-position program without weakening a positive;
that outcome would show that the portable program is more spatially compact
than the primary construction.

## Verdicts

- `CONTEXT_COMPILED_LATENT_INSTRUCTION`: every oracle, portable-code,
  mediation, contextualization and specificity gate passes.
- `CONTEXTUAL_COMPILER_WITHOUT_PORTABLE_CODE`: exact early states generate the
  correct later computation broadly, but the training-derived code does not.
- `PORTABLE_STEERING_WITHOUT_NATIVE_COMPILATION`: the training-derived code
  moves the route, but native-state generation, mediation or receiver-specific
  reconstruction fails.
- `NO_EARLY_COMPILATION`: the late target is interpretable but exact early
  target states do not generate the later target computation broadly.
- `CALIBRATION_CODE_NULL`: the training-derived code fails its pre-test
  calibration gate; held-out targets are not evaluated.
- `CAUSAL_TARGET_UNRESOLVED`: the exact matched L21 oracle fails to establish
  the target route.

No wording, family, lexical panel, split, layer, scale, site, threshold,
random seed or verdict rescue follows the output.
