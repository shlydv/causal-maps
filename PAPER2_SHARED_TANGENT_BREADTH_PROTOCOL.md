## Decision rule

`BROAD_SHARED_CAUSAL_TANGENT` requires both:

1. broad processed-state transport across families, directions, histories,
   and both lexical panels, while outperforming every frozen random control;
2. positive downstream causal-propagation movement on enough exact-oracle
   resolved cells, in both lexical panels, and above the frozen random,
   sign-reversal, and instruction controls.

A state-only result is explicitly
`SHARED_STATE_TANGENT_WITHOUT_CAUSAL_PROPAGATION`; it is not called a
controller. If the state gate fails, the shared-controller branch is closed.

No family, wording, row, vector, layer, position, random seed, outcome,
metric, or threshold changes follow the model output.
