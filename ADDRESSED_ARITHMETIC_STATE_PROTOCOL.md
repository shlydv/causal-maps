# Addressed arithmetic state (discovery)

Version 2026-07-14-v2. This uses the already behavior-qualified addition task;
it does not reopen the failed add-to-subtract program-controller hypothesis.
Twelve rows keep the addition program and second operand fixed while changing
the first operand by +2. G0 requires >=90% accuracy on both natural operands.

At the fixed first-operand address and L2, compare the raw neutral-carrier
digit-state difference, raw token-embedding difference, and a wrong +1 digit
direction. The neutral write must reproduce the natural +2 answer change on
>=80% of rows, match natural effect within [.70,1.30], and beat the wrong
direction. Exact matched CLEAN/NATURAL final-query states are exchanged at
layers 4/8/12/16/20/26 to discover the earliest sufficient arithmetic
workspace candidate. These matched patches are descriptive and cannot support
a reusable latent-controller claim without later cross-fitting.

Version 1 was mechanically invalid for the intervention: Qwen tokenizes the
space before a digit separately, and the generic character anchor selected that
shared whitespace token rather than the changed digit token. Consequently all
three v1 deltas were exactly zero. Version 2 locates the unique changed digit
token in both arithmetic prompts and neutral donors. Task, rows, layers,
comparators, and thresholds are unchanged. The v1 matched final-query exchange
did not use the faulty operand index and remains descriptive evidence that L26
is interchangeable.
